Operate securely

Juardrails stores policies and evaluations in SQLite, writes a durable audit log, and calls a configured Jev provider for live decisions. Treat it as a single-server policy service, with the surrounding application responsible for enforcement.

Configure a Jev provider

The server loads an optional .env file in its working directory. Existing environment variables take precedence. Provider keys remain on the server; CLI credentials live separately in ~/.juardrails.

SettingPurpose
JEV_PROVIDERtypesafe (default), openrouter, requesty, or custom
TYPESAFE_API_KEYTypeSafe preset credential
OPENROUTER_API_KEYOpenRouter preset credential
REQUESTY_API_KEYRequesty preset credential
JEV_API_KEYExplicit credential override for the selected provider
JEV_ENDPOINT_URLFull custom endpoint URL
JEV_API_FORMATsystemone or questions-chat
JEV_DEFAULT_MODELModel substituted for a policy’s jev-latest alias

Use a versioned model ID in the policy when reproducibility matters. The actual returned model is recorded on live evaluation. These model judgments are probabilistic: calibrate questions and thresholds against representative data before enforcing them.

Server and deployment

The installed juardrails executable serves the Web UI, API, and CLI. It listens on 127.0.0.1:8080 by default. Set -addr, -db, and -audit-log to choose the listener, SQLite file, and append-only audit file. Use the same database and audit paths with juardrails bootstrap. Put a public deployment behind HTTPS and set JUARDRAILS_COOKIE_SECURE=true when TLS terminates at a reverse proxy.

juardrails bootstrap -db data/juardrails.sqlite -audit-log data/audit.jsonl
juardrails \
  -addr 127.0.0.1:8080 \
  -db data/juardrails.sqlite \
  -audit-log data/audit.jsonl

Preserve the database and audit file across restarts. The SQLite store uses WAL and foreign keys. Stop the server before copying its database for a backup; for online backups use SQLite backup facilities rather than copying only the main file. This is a single-server deployment, not a distributed secret vault.

Auditing and retention

The file audit log records request, authorized, and response events. It includes time, request ID, method, path, namespace, action, actor and token IDs, source IP, target, status, and duration. It excludes request and response bodies, passwords, token secrets, provider credentials, and evaluation input. Policy revisions and evaluation answers remain in SQLite.

The audit file is append-only from the application and fsynced for durability. If the initial or authorization write fails, the action does not proceed. If the final completion write fails after a mutation has committed, the API returns 503; inspect current state before retrying. The database and file are not one atomic transaction. Restart after external audit-log rotation.

Revisions and audit records have no automatic pruning. Policy listings are currently unpaginated; evaluation history uses a bounded limit. Plan disk capacity and retention accordingly.

Migrate older data

Default startup imports data/juardrails.db from bbolt into an empty data/juardrails.sqlite. The source remains read-only and is retained. Stop the old server before migrating. For custom paths, use -db destination.sqlite -migrate-bbolt source.db; import into a nonempty destination is rejected.

Rego execution has been removed. Existing all, any, and weighted policies retain their behavior. For a historical Rego policy, explicitly remove the Rego text, choose a supported mode, adjust criteria, simulate representative cases, and save a new revision.

Security boundaries

Authenticate and scope

Use short-lived, least-privilege service tokens. Only an explicit global admin grant enables service administration.

Enforce the result

The API reports decisions. Your caller must treat every outcome except allow as non-authorizing.

Protect input data

Raw state is not persisted by Juardrails, but live state is sent to the selected provider.

Back up and rotate

Protect database, audit, and credential files; rotate service tokens before expiry.
