Essentials · Distribution

Install one executable

A Juardrails release contains one self-contained executable for your operating system and CPU. The same file starts the server, bootstraps its administrator, and runs the service-account CLI. You do not need Go, Node.js, or a separate CLI download.

Quick install

macOS or Linux

Download the installer, inspect it if you wish, then run it. It verifies the release binary against SHA256SUMS and installs to ~/.local/bin.

curl -fL https://github.com/abhaybhargav/juardrails/releases/latest/download/install.sh -o install-juardrails.sh
sh install-juardrails.sh
export PATH="$HOME/.local/bin:$PATH"
~/.local/bin/juardrails version

Windows PowerShell

The installer checks the release SHA-256 and copies juardrails.exe to your local app data directory.

Invoke-WebRequest https://github.com/abhaybhargav/juardrails/releases/latest/download/install.ps1 -OutFile install-juardrails.ps1
.\install-juardrails.ps1
& "$env:LOCALAPPDATA\Juardrails\bin\juardrails.exe" version

The installers print the destination and tell you if it needs to be added to PATH. Set JUARDRAILS_VERSION=v0.1.0 to pin a release, or JUARDRAILS_INSTALL_DIR to choose another directory. On PowerShell, set these as environment variables before running the script.

Manual download

Choose one file from the latest GitHub release, verify it with the release's SHA256SUMS, rename it to juardrails (or juardrails.exe on Windows), and place it on PATH.

First run

On the server machine, set TYPESAFE_API_KEY in the environment or a .env file, then bootstrap and start the service:

juardrails bootstrap
juardrails
# Open http://127.0.0.1:8080

Bootstrap saves the human admin password under data/bootstrap-admin.json and injects a dedicated service-account token into ~/.juardrails/credentials.json. Change the human password after signing in and remove the bootstrap file. The CLI always reads its local service credential from that standard path; it does not accept a human session token.

juardrails cli list
juardrails cli explain POLICY_ID
juardrails cli evaluate POLICY_ID state.json
CLI on another machine

Install the same executable there and have an administrator provision a service token with only the needed namespace actions. Inject {"url":"https://your-server","token":"jrd_..."} into ~/.juardrails/credentials.json. On Unix, its directory must be mode 0700 and the file mode 0600. On Windows, restrict both ACLs to your user, SYSTEM, and Administrators; the CLI checks this before use.

How releases are built

GitHub Actions runs the Go and policy-pack tests, cross-compiles all six targets with CGO_ENABLED=0, and stores build artifacts on pushes and pull requests. A version tag such as v0.1.0 publishes those binaries and SHA-256 checksums as a GitHub release. The web UI and its assets are embedded in each executable.

Continue with Get started for your first policy or the CLI guide for command details.
