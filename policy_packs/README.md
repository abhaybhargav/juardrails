# Policy packs

Policy packs contain versioned Juardrails YAML policies and adapters for a specific agent or deployment. The [Claude Code pack](claude-code/README.md) screens tool calls through a hook, and the [Kubernetes security pack](kubernetes-security/README.md) deploys a validating admission webhook. The reusable [Juardrails skill](claude-code/skills/juardrails/SKILL.md) can be copied into other agents' skill directories; the Claude Code hook is specific to Claude Code.
